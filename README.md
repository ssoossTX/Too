# MMORPG Кликер

Веб-игра MMORPG-кликер с системой классов, улучшений, экспедиций, подземелий и обширной коллекцией предметов.

## Особенности игры

- **Система классов:** воин, исследователь, торговец и их комбинации
- **Улучшения:** повышение силы клика, автокликер, престиж
- **Экспедиции:** отправляйте команды на поиски сокровищ
- **Подземелья:** прокачивайте персонажа и сражайтесь с монстрами в башнях
- **Профиль:** развивайте навыки и улучшайте экипировку
- **Коллекционирование:** собирайте артефакты и скины

## Технические детали

- Игра построена на React, Redux, TypeScript, Tailwind CSS
- Все данные сохраняются в localStorage вашего браузера
